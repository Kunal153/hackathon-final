# Vercel Deployment Guide for EngiNotes (React + Vite)

This repository is fully configured and ready for **1-click or CLI deployment to Vercel**.

---

## 🚀 Quick Deploy Options

### Option 1: Deploy with Vercel CLI (Fastest)

1. Open your terminal in this project root (`c:\hackathon-final`).
2. Run the Vercel CLI command:
   ```bash
   npx vercel
   ```
   *(Or install globally: `npm i -g vercel` then run `vercel`)*
3. Follow the CLI prompts:
   - **Set up and deploy?** `Y`
   - **Which scope?** (Select your personal account or team)
   - **Link to existing project?** `N`
   - **What's your project's name?** `enginotes` (or your preferred name)
   - **In which directory is your code located?** `./`
   - **Want to modify build settings?** `N` (auto-detected via `vercel.json`)
4. To deploy to production:
   ```bash
   npx vercel --prod
   ```

---

### Option 2: Deploy via GitHub / GitLab / Bitbucket

1. Push this repository to your GitHub account:
   ```bash
   git add .
   git commit -m "Configure Vercel deployment with React & Serverless API"
   git push origin main
   ```
2. Go to [https://vercel.com/new](https://vercel.com/new).
3. Import your GitHub repository.
4. Vercel will automatically detect the settings:
   - **Framework Preset**: `Vite`
   - **Root Directory**: `./`
   - **Build Command**: `vite build` (or `npm run build`)
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
5. Click **Deploy**.

---

## 🔑 Environment Variables Configuration

If you want the AI features (Brahmāstra AI Problem Solver & Smart PDF Summarizer) to use your Google Gemini API key:

1. In your Vercel Dashboard, go to:
   **Project Settings** → **Environment Variables**
2. Add the following key:
   - **Key**: `GEMINI_API_KEY`
   - **Value**: `Your_Gemini_API_Key_Here`
3. Click **Save** and trigger a redeploy (or deploy new commit).

> **Note:** If `GEMINI_API_KEY` is not provided, the app automatically switches to the built-in intelligent offline fallback engine, ensuring the app never breaks!

## ⚙️ Architecture & Configurations Included

- **`vercel.json`**:
  - Handles single-page app (SPA) routing so page refreshes (`/branches`, `/my-account`, etc.) work without 404s.
  - Automatically routes `/api/(.*)` requests to Vercel serverless functions in the `api/` folder.
- **Serverless API Functions (`/api`)**:
  - `POST /api/gemini/solve`: Brahmāstra AI academic solver.
  - `POST /api/gemini/summarize-pdf`: Smart PDF notes and syllabus unit revision summarizer.
  - `POST /api/gemini/last-minute-notes`: High-yield exam revision notes generator.
  - `GET /api`: API status and health check.
- **`dist/` Directory**:
  - Contains the production-optimized React SPA bundle generated by Vite with Tailwind CSS v4, Lucide icons, and Motion animations.
